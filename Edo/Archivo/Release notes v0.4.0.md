# EihwazOS / Dual-LLM Continuity Kit v0.4.0

## Incluye

- EihwazOS V1 como plugin local de Obsidian: portada de constelación, nodos dinámicos por áreas reales y buscador nativo.
- Contexto Cencosud organizado por `Mi Local`, `Applied IA` y `Modernización`, con tareas, fuentes, proyectos e hilos clasificados.
- Skills para Claude Code: `mock-frontend`, `itds-code-forge` e `itds-board-composer`.
- Exportación portable actualizada para incluir el plugin EihwazOS, el contexto Cencosud y las skills.

## Validado

- `bash agent-kit/scripts/validate-kit.sh .`
- `node --check .obsidian/plugins/eihwazos-v1/main.js`
- Exportación ZIP del kit.

## Pendiente conocido

- Validación visual manual en Obsidian: activar el plugin, abrir la portada, probar nodos, búsqueda y teclado.
