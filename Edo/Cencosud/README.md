## Modelo de organización

La ruta de cada contexto es:

`organización → programa → proyecto o capacidad → tema`

La lectura de producto evita partir por pantallas y usa esta secuencia:

`Problema → Capacidad → Configuración → Agente → Datos → Reglas → Herramientas → Observabilidad → Métricas → Roadmap`

## Separación Cencosud–VERNO

- Cencosud contiene trabajo corporativo, decisiones, fuentes y estado operativo.
- VERNO/EihwazOS contiene investigación personal, infraestructura del Second Brain y patrones reutilizables.
- Un patrón puede pasar de VERNO Agent OS a Applied IA, pero su implementación y evidencia corporativa se documentan aquí.
- El proyecto personal [[../Proyectos/Panel Edu y Schema Workbench/README|Panel Edu y Schema Workbench]] no es el Portal de Capacidades Agénticas.
