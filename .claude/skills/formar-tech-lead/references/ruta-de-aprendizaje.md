# Ruta de aprendizaje hacia Tech Lead

## Objetivo

Avanzar desde una base lógica y experiencia desactualizada en JavaScript hacia liderazgo técnico de alcance medio. La progresión es por evidencia, no por cantidad de cursos completados.

## Etapa 0 — Diagnóstico y entorno

- Explicar variables, funciones, objetos, colecciones, asincronía, módulos y flujo HTTP.
- Leer un repositorio, ejecutar scripts, usar Git y depurar errores básicos.
- Producir una pequeña funcionalidad y explicar sus decisiones.

Salida: mapa de fortalezas, brechas y primer proyecto-laboratorio.

## Etapa 1 — Desarrollo web moderno

- JavaScript moderno: scope, closures, módulos, promesas, `async/await`, errores e inmutabilidad pragmática.
- TypeScript: tipos, uniones, genéricos básicos, narrowing y contratos.
- Web: HTML semántico, CSS responsive, accesibilidad, navegador y APIs.
- React: componentes, props, estado, efectos, formularios, composición y manejo de datos.
- Pruebas: unidad, integración y criterios de aceptación.

Salida: una funcionalidad frontend pequeña, probada y explicada.

## Etapa 2 — Ingeniería de producto

- Diseño de APIs, validación, autenticación y manejo de estados de error.
- Estructura de repositorios, dependencias, build, CI y ambientes.
- Modelado de datos, caché, rendimiento y observabilidad básica.
- Git colaborativo, pull requests y revisión de código.

Salida: un flujo vertical completo desde interfaz hasta persistencia o API.

## Etapa 3 — Diseño técnico

- Separación de responsabilidades, módulos, límites y deuda técnica.
- Arquitecturas frontend y backend según escala real.
- Seguridad, privacidad, disponibilidad, costos y operación.
- Documentos técnicos: ADR, RFC, diagramas y planes de migración.
- Evaluación de tradeoffs y decisiones reversibles/irreversibles.

Salida: diseño y ejecución de una mejora transversal con métricas y rollback.

## Etapa 4 — Liderazgo técnico

- Descomponer requerimientos ambiguos y alinear alcance con producto.
- Estimar con incertidumbre, gestionar riesgos y secuenciar entregas.
- Dar feedback de código, enseñar, delegar y elevar estándares.
- Coordinar incidentes, retrospectivas y mejora continua.
- Comunicar decisiones técnicas a personas técnicas y no técnicas.

Salida: liderar una iteración de principio a fin con evidencia de resultado.

## Regla de selección

Elegir el ejercicio más pequeño que exponga la siguiente brecha importante. Reutilizar Portal de Capacidades, Edo u otros proyectos reales solo cuando el riesgo sea controlable y el objetivo pedagógico esté claro.
