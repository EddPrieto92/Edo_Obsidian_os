# Integraciones

## Obsidian

Abrir la carpeta que contiene `Edo/` como vault. No crear otro vault dentro de ella. Los archivos del kit son Markdown estándar y pueden editarse desde VS Code.

## Git y GitHub

Usar Git como historial único. Registrar el remoto en `Edo/IA/Agentes/06 - Integraciones y fuentes.md`. Las acciones de publicar, fusionar o etiquetar requieren autorización explícita.

## Google Drive

Registrar enlaces o identificadores de fuentes en notas de tipo `fuente`. Mantener adjuntos pesados fuera del ZIP salvo selección explícita. No sincronizar bidireccionalmente la misma carpeta mediante varios servicios sin una política de conflictos probada.

## VS Code

Abrir uno de los archivos de `workspaces/`. En un repositorio con worktrees reales, actualizar el campo `path` para que apunte al worktree del agente correspondiente.
